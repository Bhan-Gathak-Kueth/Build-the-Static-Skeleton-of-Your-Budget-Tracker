# Budget Tracker

## Project Description

This project is a static Budget Tracker website built using HTML and CSS. It provides a basic visual layout for tracking income and expenses.

## Files in This Project

### `index.html`

Contains the structure of the webpage, including:

* The main heading, **My Budget Tracker**
* A short description of the website
* An Add Expense section with input fields
* An expenses section

### `style.css`

Controls the appearance of the webpage, including colors, spacing, fonts, and layout.

## Technologies Used

* HTML5
* CSS3

## Current Features

* Displays the Budget Tracker page layout.
* Provides input fields for an expense name, amount, and category.
* Shows a section for displaying expenses.

## Learning Objective

The goal of this project is to practise structuring a webpage with HTML and styling it with CSS.

## Note

This is a static prototype. Expense calculations and interactive functionality have not been implemented.
